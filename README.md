# CausaAI - OPTT

Aplicação web estática para análise e justificativas de atrasos.

## Uso local

Abra `index.html` por um servidor HTTP local. A aplicação também pode ser publicada diretamente em uma hospedagem estática, como GitHub Pages.

> A chave de API informada na interface é armazenada somente no navegador do usuário. Nunca inclua chaves ou arquivos `.env` no repositório.
